# Public samples on GitHub Pages

- Main guide: https://usedhonda.github.io/seichi-junrei/
- Different-work example: https://usedhonda.github.io/seichi-junrei/alice/

Both are generated by `plugins/seichi-junrei/scripts/render_guide.py`, using the
same templates/runtime installed with the skill. The main example is
`plugins/seichi-junrei/examples/egypt_guide.json`; the second is
`plugins/seichi-junrei/examples/oxford_alice_guide.json`.

Push changes to the plugin, `site/` or Pages scripts on main. Actions builds,
checks mobile behavior against the actual HTML, and deploys only after success.
The Tests workflow additionally tests both guides in an isolated plugin copy.
The workflow's explicit paths include the plugin so template/code changes deploy.

Only `_site/` is published. Personal reservation data is excluded from the sample;
the itinerary uses explicitly labelled model data. Noindex and robots.txt discourage
indexing but are not authentication. Pages is public.

The original expired sandbox ZIP was rebuilt from the corrected HTML attachment.
Original assets and source are retained under `site/` as provenance. Manual ZIP
upload is no longer part of normal setup/update. `import_mobile_bundle.py` retains
its checksum-bound historical archive recovery behavior and does not overwrite
an existing site. Do not call that archive the current plugin distribution.

Phone-width Chromium checks do not establish physical iPhone/Safari acceptance.
The separate Oxford guide validates a different work, 3 destinations, 3 days,
named story IDs and a different mission count; it uses sourced book illustrations,
not a new native ImageGen generation benchmark.
